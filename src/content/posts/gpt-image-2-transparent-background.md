OpenAI가 GPT Image 2의 투명 배경 출력 기능을 공개했습니다.
이번에는 Codex에 OpenAI API 키를 연결한 뒤 OpenAI Image API를 호출하는 방식으로 써봤습니다.

![Codex에서 Image API를 거쳐 투명 PNG가 나오는 흐름](/uploads/1791783464000-gpt-image-2-flow.png)

## 시작 전에

ChatGPT·Codex 구독과 API 이용료는 따로 계산됩니다.
그래서 API 결제 설정을 먼저 해 둬야 하고, 이미지를 생성하거나 편집할 때마다 비용이 나갑니다.

API 키를 `OPENAI_API_KEY` 환경변수에 넣어 두면, 그다음부터는 Codex 새 채팅에 요청만 입력하면 됩니다.

## 1. 새 이미지 만들기

고양이 스티커를 하나 만들어 달라고 했습니다.

> 환경변수 OPENAI_API_KEY에 설정된 OpenAI API 키를 사용해 OpenAI Image API로 아래 이미지를 생성해줘. 투명 배경의 귀여운 고양이 스티커 이미지가 필요해. 주황색과 흰색 털의 고양이가 앉아서 한쪽 앞발을 흔드는 모습이야. 고양이 전체와 꼬리가 모두 보이게 하고, 얇은 흰색 스티커 테두리를 둘러줘. 배경은 체크무늬나 흰색으로 그리지 말고 실제 알파 채널이 포함된 투명 PNG로 만들어줘.

마지막 문장이 중요합니다.
"투명 배경"이라고만 쓰면 투명을 표현하는 체크무늬를 그림으로 그려 넣는 경우가 있습니다.
그렇게 나온 이미지는 다른 배경 위에 올려도 체크무늬가 그대로 보입니다.

![체크무늬를 그린 이미지와 알파 채널이 있는 PNG 비교](/uploads/1791783464000-gpt-image-2-alpha.png)

## 2. 기존 이미지 누끼 따기

이번에는 Codex 새 채팅에 곰 캐릭터 이미지를 첨부하고, 배경만 지워 달라고 했습니다.

> 환경변수 OPENAI_API_KEY에 설정된 OpenAI API 키를 사용해 OpenAI Image API의 이미지 편집 기능으로 아래 작업을 처리해줘.
>
> 첨부한 이미지에서 곰은 그대로 유지하고 배경만 제거해줘. 안경, 귀와 머리 주변의 가는 털, 셔츠와 앞치마의 가장자리를 자연스럽게 보존해줘. 배경색 잔여물과 테두리 번짐 없이 실제 알파 채널이 포함된 투명 PNG로 만들어줘. 곰의 얼굴, 표정, 색상, 비율과 구도는 바꾸지 마.

결과는 배경 없이 깔끔하게 나왔습니다.

편집 요청에서는 남길 부분을 구체적으로 적는 게 좋았습니다.
가는 털이나 옷 가장자리처럼 경계가 애매한 곳을 짚어 주고, 얼굴·색상·구도는 바꾸지 말라고 못 박아 두면 배경만 지워집니다.

## 정리

- 투명 배경이 필요하면 "알파 채널이 포함된 투명 PNG"라고 분명히 적습니다.
- 체크무늬나 흰색 배경으로 그리지 말라는 말도 함께 넣습니다.
- 누끼를 딸 때는 보존할 부분과 바꾸면 안 되는 부분을 같이 적습니다.
- API 요금은 구독과 별도로 나갑니다.
