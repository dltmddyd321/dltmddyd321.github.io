9월 29일에 OpenAI DevDay 2026이 열렸습니다.
발표가 20개를 넘어서 기사만 훑어봐도 양이 꽤 됐습니다.
그래서 Claude에게 요약을 맡기고 내친김에 인스타그램 카드뉴스까지 만들어 봤습니다.
결과물과 함께 어떤 프롬프트를 썼는지 기록해봅니다.

카드에 들어간 내용은 공식 리캡과 9to5Mac, Engadget 같은 매체 기사를 모은 것입니다.
Pro 500 요금제 가격처럼 기사마다 다르게 나온 부분은 카드에도 "공식 가격 확인 필요"라고 적어 두었습니다.

## 사용한 프롬프트

작업은 Claude Code 한 세션 안에서 끝냈습니다.
실제로 입력한 프롬프트는 아래 다섯 개입니다.

```text
https://openai.com/ko-KR/index/devday-2026-recap/
Chat GPT DevDay가 진행되었는데, 그에 대한 중요한 요약 사항들을 정리해줘
```

```text
이걸 우주 배경으로 한 인스타 카드 뉴스로 정리 가능해?
```

```text
8장 모두 png로 다운로드 폴더에 넣어줘
```

```text
20개가 넘는 발표, 꼭 알아야할 6가지는 너무 내용을 압축한 티가 나 적절한 소개문구를 다시 작성해봐
```

```text
그리고 인스타 스토리에 한 컷으로 올리기 좋도록 주요 내용을 문장 단위로 압축한 페이지도 따로 만들어줘
글씨 폰트 작아도 괜찮아
```

중간에 덜 중요한 내용은 빼 달라는 요청을 한 번 더 넣었습니다.
디자인을 세세하게 지시한 건 "우주 배경" 한마디가 전부였습니다.

## Claude가 한 일

요약 단계에서는 링크를 열어 읽으려 했지만 공식 한국어 페이지가 403으로 막혔습니다.
Claude가 알아서 영문 원문과 매체 기사 몇 개를 찾아 읽고 기사끼리 표현이 다른 부분은 따로 표시해서 정리해 줬습니다.

카드뉴스는 Claude의 Artifact 디자인 캔버스에 1080×1350 보드를 8개 깔고 장마다 HTML로 그리는 방식이었습니다.
검은 우주 배경에 별과 보랏빛 성운을 깔고 장마다 행성·달·궤도 위치를 다르게 잡았습니다.
제목은 Space Grotesk, 본문은 IBM Plex Sans KR을 썼습니다.

PNG는 Chrome headless로 각 보드를 렌더링해서 뽑았습니다.
스토리 요약본은 위아래로 프로필과 답장창이 겹치는 걸 감안해서 위아래 여백을 250px 정도씩 비워 뒀습니다.
처음 뽑았을 때 "토큰/당"처럼 단어 중간에서 줄이 넘어가는 곳이 있었는데, 단어 단위로 줄이 바뀌게 고쳐서 다시 뽑았습니다.

## 손을 댄 부분

표지 제목은 처음에 "20개 넘는 발표, 꼭 알아야 할 6가지"였습니다.
틀린 말은 아니지만 숫자로 내용을 압축한 티가 너무 났습니다.
다시 써 달라고 하자 발표 전체를 관통하는 흐름을 제목으로 잡아 "이제 ChatGPT가 일을 맡아서 합니다"로 바꿨고, 마지막 장의 "AI가 대화 상대에서 쉬지 않는 동료로"와도 앞뒤가 맞게 됐습니다.

Claude가 렌더링 결과를 전부 열어 보지는 않았습니다.
8장 중 표지와 API 장만 열어 봤고 나머지 6장은 확인하지 않았다고 따로 알려 줬습니다.

## 정리

- 기사 수집부터 요약, 디자인, PNG 추출까지 프롬프트 몇 개로 끝났습니다
- 매체마다 수치가 다른 부분은 Claude가 먼저 짚어 줬고 카드에도 그대로 남겼습니다
- 제목처럼 글맛이 걸리는 부분은 사람이 한 번 더 봐야 합니다
- 렌더링 결과는 직접 넘겨 보며 확인하는 게 안전합니다
